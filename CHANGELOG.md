# Changelog

## 1.0.0

Complete rewrite.

- New WebGL renderer (Sigma.js) with ForceAtlas2 layout and cluster colours
- Documents mode: bullets roll up into their document
- Reference edges, read straight from rich text (no per-Rem API calls)
- Local graph in the right sidebar and an **Open Local Graph** command
- Search, click to open, hover highlighting, zoom controls
- Filters: hierarchy, references, orphans, daily documents; powerups are hidden
- Dark mode
- Read-only permission
